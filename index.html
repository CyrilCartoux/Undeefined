FAQ

Combien de temps pour un premier agent ?

Entre 4 et 8 semaines selon la complexité et les intégrations. L’audit fixe un planning réaliste.

Vous travaillez avec quelles stack / APIs ?

Node/TypeScript, Python, intégrations REST et webhooks. CRM (HubSpot, Pipedrive…), outils de support, bases de données. On s’adapte à votre existant.

Où sont hébergés les agents ?

Chez vous (VPC, serveur) ou sur une infra cloud (AWS, GCP, etc.). Pas de lock-in : vous gardez le code et la main.

Et la confidentialité des données ?

Les données restent dans votre périmètre. Pas d’entraînement sur vos données pour des modèles tiers. Conformité RGPD prise en compte dès la conception.
